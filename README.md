## 🔥 核心功能特性

### 1. 🎯 智能筛选与高管优先排序
* **4 维精确筛选**：支持按求职类型、工作经验、学历要求、公司规模等维度在 BOSS URL 参数级过滤。
* **老板/法人直招识别**：自动识别 HR 职位（如创始人、CEO、总经理、法人），标记 `👔直招`。
* **HR 职级排序去重**：同一公司若有多个岗位，自动只保留 HR 职级最高的岗位优先沟通。

### 2. 🤖 千岗千面 AI 针对性招呼语
* 结合求职者简历与岗位 JD，调用 DeepSeek 大模型自动生成个性化针对性打招呼短语（带 24 小时本地缓存，避免重复消耗 Token）。

### 3. ⏱ 智能调度系统（3 个独立控制开关）
* **仅工作日投递**：周末自动挂起，周一恢复。
* **避开午休时段**：每天 12:00 ~ 14:00 自动暂停，14:00 后自动恢复。
* **自适应间隔**：每投递 3 个岗位自动暂停 30 秒，模拟真实人工操作节奏。

### 4. 📜 已投递历史管理与再次投递双重去重
* **实时历史面板**：侧边栏内置“已投递历史”卡片，展示已投岗位的名称、公司、HR、薪资及投递时间。
* **搜索与清理**：支持按关键词搜索历史记录；支持单条记录删除（删除后可对该岗位重新投递）及一键清空历史。
* **双重去重**：再次运行海投时，自动对比`岗位 ID`、`规范化公司名_岗位名` 以及 `已投公司集合`，精准拦截已投岗位。

### 5. 📋 审核确认列表保留与实时状态流转
* **列表持续保留**：收集/筛选岗位完成后生成列表，点击【投递选中】后列表保持展开，不消失。
* **状态徽章实时流转**：
  - `待投递` (灰色) ➔ `⏳ 投递中...` (蓝色高亮) ➔ `✓ 成功` (绿色) / `✕ 失败` (红色，悬浮查看原因)
* **批次重试**：投递完成后解锁控制，方便对未选中或失败的岗位直接进行重试。

## 🔑 商业化与卡密生成

### 卡密系统全流程
1. **生成卡密**：在 `boss-worker/` 目录下运行 Node 脚本批量生成卡密并输出 wrangler 上传 JSON：
   ```bash
   cd boss-worker
   node scripts/generate-cards-bulk.js [生成数量] [每张卡密额度]
   # 示例：生成 100 张卡密，每张含 100 次投递额度
   node scripts/generate-cards-bulk.js 100 100
   ```
2. **导入 Cloudflare KV**：
   ```bash
   npx wrangler kv key put --namespace-id=a24b19824de24961b48270384f6bb613 --bulk scripts/cards-bulk.json
   ```
3. **用户兑换**：用户在发卡平台购买卡密（如 `BOSS-A1B2C3D4`），在插件侧边栏“额度与充值”板块输入即可秒级充值到账。

## 🛠 插件开发与混淆构建

如修改了 `boss-extension/src/` 中的源码，在发布前运行打包混淆脚本：

```bash
cd boss-helper1.1.1/boss-extension
node build.js
```

混淆构建产物将输出在 `boss-extension/dist/` 目录，在 Chrome `chrome://extensions` 中加载该目录即可。
