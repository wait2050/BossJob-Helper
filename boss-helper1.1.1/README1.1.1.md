## 桌面端新增功能详解

### 1. 结构化简历编辑器

简历管理页新增「📋 结构化编辑」Tab，表单式填写：

- **基本信息**：姓名、籍贯、邮箱、电话、政治面貌、主页、地址（8 字段）
- **教育经历**：动态添加/删除，每项含学校、专业、学历、时间、GPA、亮点
- **实习经历**：动态条目，每项含公司、岗位、时间、概述、STAR 要点
- **项目经历**：STAR 结构化表单（Situation→Action→Result→关键词）+ 字符计数 + 预览模式
- **技能**：英语/编程/AI/工具/硬件/其他，6 大分类
- **获奖 + 学生工作**：动态列表管理

### 2. 投递状态追踪

Dashboard 全新升级：

- **6 个统计卡片**：总投递 / 简历初筛 / 面试中 / 待面试 / 待笔试 / Offer
- **Kanban 8 列看板**：未投递 → 简历初筛 → 待笔试 → 待面试 → 面试中 → 面试通过 → 未通过 → Offer
- **状态时间线**：点击职位详情 →「状态历史」Tab，查看每次状态变更记录
- **状态备注**：每次改状态可填写备注（如"HR 已查看简历"）

### 3. 岗位-简历匹配策略

- **5 种公司类型**：私企 / 国企 / 外企 / 事业单位 / 科研院所
- **自动策略**：政治面貌去留、学生工作删除/精简/保留、项目/技能优先级排序、语调调整
- **策略面板**：职位详情 →「简历策略」Tab，可手动配置或一键自动填充
- **批量定制**：勾选多个职位 → 选择主简历 → 一键生成多份定制版简历

### 4. PDF 简历导出

简历列表点击 🖨️ 按钮：
- 结构化数据渲染为精美的 A4 简历页面
- 深蓝 #1E3A8A 主色调 + 灰白 #F8FAFC 卡片布局
- 个人信息横向排列 + 照片位 + 教育/实习/项目左中右时间线
- 预览窗口 → `Ctrl+P` → 浏览器另存为 PDF

### 5. AI 模拟面试改版

- **旧版**：必须先在职位追踪中收集 JD、先在简历管理中创建简历，才能从下拉框选择
- **新版**：打开模态框 → 直接输入公司名 + 岗位名 + JD 文字 + 简历文字（可从简历管理导入，也可手动粘贴或留空）
- AI 内置 6 阶段面试提示词（开场→技术→项目→综合素质→反问→评估报告），用户无需写 prompt

### 6. Bug 修复

- **AI 优化 404**：`rewrite`/`greeting`/`interview`/`analyze-jd` 四个端点 URL 缺少 `/chat/completions` 后缀，已统一修复
- **AI 分析 0 分**：JSON 解析正则只能匹配 2 层嵌套，改为花括号计数法支持任意深度

### 7. UX 优化

- 扩展端简历文本 placeholder 更友好
- 桌面端简历标题输入框增高、操作栏居中
- AI 设置 API Key 新增 👁️ 眼睛按钮查看明文

## 启动方式

**方式一：源码运行**
```bash
cd boss-desktop-app
pip install -r requirements.txt
python app.py
```

**方式二：一键启动**
双击 `Boss_helper.exe`，无需安装 Python 或任何依赖，自动打开浏览器仪表盘。
